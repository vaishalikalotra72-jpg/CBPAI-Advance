# CBPAI Advance

Programme page for the CBPAI cohorts (Capacity Building Programme in AI), VLED Lab, IIT Ropar, under the UGC Malaviya Mission Teacher Training Programme (MMTTP).

Live page: https://vaishalikalotra72-jpg.github.io/CBPAI-Advance/  (one cohort: add `?c=ADV07`)

## Updating the content

The schedule, cohorts and notices come from the Google Sheet **CBPAI Cohorts** (tabs: Cohorts, Days, Sessions, Notices). Edit the sheet and the page updates; no code change is needed. The sheet must stay shared as *Anyone with the link: Viewer*.

If the sheet can't be reached, the page shows the last schedule it loaded, or the copy built into `index.html`.
